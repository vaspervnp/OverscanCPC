# Sprite art. A ":" line names a sprite, then its rows.
#
#   .           transparent - the background shows through
#   0-9 A-F     pen number
#
# Rows must all be the same length and an even number of pixels, because mode 0
# packs 2 pixels to a byte and sprites are blitted on byte boundaries. A mode 0
# pixel is two mode 1 pixels wide, so the cat being 12 pixels across here is
# the same 48/384ths of the screen the 24 pixel mode 1 cat was: half the
# samples, the same size, and sixteen pens instead of four.
#
# In-game palette, from pal_play in src/play.asm:
#   0 navy      1 coral     2 butter yellow  3 white
#   4 black     5 grey      6 olive          7 orange
#   8 dk green  9 green     A teal           B cyan
#   C dk red    D red       E purple         F pale yellow
#
# tools/mksprite.py turns this into src/sprites.asm.
