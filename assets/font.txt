# 5x8 bilingual font - Latin + Greek uppercase, digits, punctuation.
#
# Each glyph is a ":" line naming it, then exactly 8 rows of 5 columns using
# "." and "#". The bottom row is the line spacing; the letter spacing is a
# sixth column the tool adds, because a mode 0 byte is two pixels and a cell
# has to be a whole number of them. So a cell is 6 pixels - 3 bytes - and text
# still advances a whole cell and never has to shift a byte.
#
# Most letters are drawn 4 wide and leave the fifth column blank; M, W, T and
# the wide Greek capitals use all five. A mode 0 pixel is two mode 1 pixels
# across, so five columns here is ten pixels on the monitor: these are large,
# square letters, not a cramped font.
#
# Greek capitals that share a Latin shape are not repeated here; the text tool
# folds them onto the Latin glyph. Only the 10 Greek-only shapes are drawn.
#
# tools/mktext.py turns this into src/font.asm. Order defines glyph indices.
