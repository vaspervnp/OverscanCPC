# 8x8 bilingual font - Latin + Greek uppercase, digits, punctuation.
#
# Each glyph is a ":" line naming it, then exactly 8 rows of 8 columns using
# "." and "#". Glyphs are drawn 6 wide and 7 tall inside the 8x8 cell, so the
# blank right column and bottom row are the letter spacing - text advances a
# whole cell and stays byte aligned in mode 1.
#
# Greek capitals that share a Latin shape are not repeated here; the text tool
# folds them onto the Latin glyph. Only the 10 Greek-only shapes are drawn.
#
# tools/mktext.py turns this into src/font.asm. Order defines glyph indices.
